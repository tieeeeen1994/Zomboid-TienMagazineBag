description=
description="Fetch Full Magazines" Radial Menu Entry
description=Hold the Reload key to gain access to the radial menu. Using this entry will move full firearm magazines from the assigned magazine bag to your main inventory.
description=
description="Store All Ammo" Radial Menu Entry
description=Hold the Reload key to gain access to the radial menu. Using this entry will move all firearm magazines and loose rounds for the held weapon from your main inventory to assigned magazine bags.
description=
description="Reload Magazines" Radial Menu Entry
description=Hold the Reload key to gain access to the radial menu. Using this entry will attempt to reload all incomplete and empty magazines from the main inventory and magazine bags.
